# Beispieldaten

Gemeinsame, unkritische Beispiel-/Testdatensätze, die von den Blanko-Notebooks eingelesen werden (z. B. Beispielmessreihen zum Einüben der Auswertung).

**Nicht** ablegen:
- echte Messdaten oder personenbezogene Daten von Studierenden,
- große Binärdateien (Repo wird bei jedem Login per `nbgitpuller` synchronisiert — hält die Datenmenge klein).
