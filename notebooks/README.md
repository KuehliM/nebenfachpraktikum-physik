# Notebook-Konvention

- `index.ipynb` — wird beim Login zuerst geöffnet.
- `00_umgebungstest.ipynb` — prüft, dass alle Pakete verfügbar sind.
- Ein Notebook pro Versuch: `NN_kurzname.ipynb`, z. B. `01_pendel.ipynb`.
- Neue Versuchs-Notebooks in der Tabelle in [index.ipynb](index.ipynb) ergänzen.

## Hinweise

- Keine Musterlösungen, keine echten/personenbezogenen Messdaten von Studierenden (Repo ist öffentlich und wird per `nbgitpuller` an alle Studierenden verteilt).
